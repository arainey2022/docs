---
title: "Improve a specific AI response"
description: "Find why an AI response was wrong, then change the correct knowledge or instruction."
---

Start with the support ticket. Echo can inspect the conversation, explain the answer, and identify the knowledge or guidance that affected it.

## Diagnose the response

1. Open Echo from the Dashboard.
2. Paste the link to the support ticket.
3. Ask why the AI agent gave that response.
4. State the part that you want to change.
5. Ask Echo to show the knowledge, guidance, or task that affected the response.

Classify the problem before you change the agent:

- The answer contains incorrect facts.
- The answer is missing facts.
- The tone is wrong.
- The AI agent handled the scenario incorrectly.
- The ticket needed a handover.

## Apply the correct fix

| Cause | Fix |
| --- | --- |
| The knowledge does not exist | Add the missing help-center content, a Custom Answer, or a published Self-learning article. |
| Two sources conflict | Correct the help-center articles and remove the outdated Custom Answer or Self-learning content. |
| The knowledge exists but was not found | Confirm that the source has synced. Improve the source heading and wording. Add a Custom Answer only if the source still cannot be found. |
| Guidance does not exist | Add Guidance for the tone, behavior, scenario, or handover rule. |
| Guidance is too broad | Narrow or split the Guidance. Use a Task for a process with several steps. |
| The configured rule was ignored | Send My AskAI support the conversation link after Echo cannot resolve the problem. |

Use [Knowledge](/features/connections) for facts. Use [Guidance](/features/improve/guidance) for behavior and tone. Use [Tasks](/features/tasks) for processes that collect information or take actions.

## Test the fix

1. Ask Echo to test the same question after the change.
2. Run the question again in **Improve \> Test**.
3. Compare the new answer with the original ticket.
4. Test one nearby example to make sure that the change is not too narrow.
5. Review the next live tickets that match the scenario.

If the answer still fails, share the ticket link or the conversation link from **Improve \> Inspect & Logs** with My AskAI support.
