# How to create an AI support agent without code

My AskAI is an AI customer service agent that works inside your existing helpdesk. You can install it through approved app and marketplace integrations for Zendesk, Intercom, Freshdesk, Freshchat, Gorgias or HubSpot. The standard setup does not need code, a developer or a custom API integration. It takes about 10–15 minutes of hands-on work. Website processing can take up to one hour.

You need a work email address, helpdesk Admin access and useful support content.

## What you can do without a developer

- Connect a help center, website or supported cloud source.
- Set tone, terminology and handoff rules.
- Connect a supported helpdesk.
- Start with private internal-note replies.
- Test historic questions.
- Turn on direct replies.

You usually need a developer for custom user-data APIs and custom Tools that change data in your systems.

## Step 1: Create the account

On the My AskAI website, select **Create AI agent**, choose your helpdesk and sign up with Google or a work email.

**SCREENSHOT NEEDED:** Current helpdesk-selection and sign-up screen.

## Step 2: Add knowledge

Connect a help center such as Zendesk, Intercom or Freshdesk, or enter the website that contains your help articles.

Use a direct help-center connection when available. It usually gives better updates and answer quality than a general website crawl.

Website processing can take up to one hour. You will receive an email when it is complete.

**SCREENSHOT NEEDED:** Current initial knowledge-connection screen.

## Step 3: Add basic guidance

Set only the rules that must be true from the first test:

- Tone and formality.
- Terms the agent must use or avoid.
- When it must ask a follow-up question.
- When it must hand the customer to a person.

Do not add a long system prompt. Use short, specific guidance entries.

**SCREENSHOT NEEDED:** Current onboarding Guidance screen.

## Step 4: Connect the helpdesk

Use the connection for your platform:

- [Zendesk Tickets](/features/channels/zendesk/zendesk-tickets)
- [Zendesk Messaging](/features/channels/zendesk/zendesk-messaging)
- [Intercom](/features/channels/intercom)
- [Freshdesk](/features/channels/freshdesk)
- [Freshchat](/features/channels/freshchat)
- [Gorgias](/features/channels/gorgias)
- [HubSpot](/features/channels/hubspot)

All connections start in a private or note-based mode where supported.

## Step 5: Review the test questions

My AskAI uses a sample of historic tickets during onboarding. Review each answer and its source. Add your own common and difficult questions.

## Step 6: Share with the team

Invite team members to test the agent. Support agents can also use the Chrome extension in supported helpdesks.

## Step 7: Launch a narrow first use case

Turn on direct replies only for a low-risk set of support questions. Keep billing disputes, safety issues, legal requests and other sensitive cases with people until you have tested explicit rules.

## Pass conditions

- The agent answers common questions from the correct source.
- It does not invent an answer when knowledge is missing.
- It hands sensitive or unanswerable requests to a person.
- A person can stop or pause replies.
- The support team knows how to inspect a wrong answer.
